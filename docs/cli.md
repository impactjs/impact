# CLI Usage

The Impact CLI provides a command-line interface for analyzing and tracking changes in your codebase.

## Basic Usage

```bash
npx impact [command] [options]
```

## Commands

- `analyze`: Analyze changes in your codebase
- `report`: Generate reports in various formats
- `init`: Initialize a new Impact configuration

## Options

- `--config`: Specify a custom config file path
- `--format`: Output format (json, yaml, html)
- `--output`: Output directory for reports

For more detailed information about each command, use:

```bash
npx impact [command] --help
```
