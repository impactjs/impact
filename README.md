# Impact

> [!IMPORTANT]
> Note that all the documentation has been generated by AI, so it may not be 100% accurate.
> I will be updating the documentation as I go along.
> If you find any issues, please report them to the [issue tracker](https://github.com/impactjs/impact/issues).

Impact is a powerful tool for analyzing and tracking changes in your codebase. It helps you understand the impact of changes across your project by analyzing file dependencies, tracking updates, and providing detailed reports.

## Features

- 🔍 **Change Analysis**: Automatically detects and analyzes changes in your codebase
- 📊 **Impact Reports**: Generate detailed reports in multiple formats (JSON, YAML, HTML)
- 🔌 **Plugin System**: Extensible architecture with support for various plugins
- 🛠 **CLI Tool**: Easy-to-use command-line interface
- 🔄 **Git Integration**: Built-in support for Git-based version control
- 📈 **Linear Integration**: Track issues and updates with Linear

## Installation

```bash
npm install @impacts/cli
# or
yarn add @impacts/cli
# or
pnpm add @impacts/cli
```

## Quick Start

1. Create an `impact.config.ts` file in your project root:

```typescript
import { defineConfig } from '@impacts/config'

export default defineConfig({
  entries: [
    {
      path: 'src',
      description: 'Source code'
    }
  ]
})
```

2. Run Impact:

```bash
npx impact
```
